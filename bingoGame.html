Bingo Settings Screen

Figure 1.1 Game Settings Screen

Looks like you are ready to start your math journey, but first you need to select your settings.


To Create the Game:

  1. 1. Select the operation that you would like to practice on.
  2. 2. Select the difficulty you would like to play one.


Bingo Start Screen

Figure 1.2: Before Start Game


Now that you have started your journey to mastering arithmetic operations, your opponent's board will be revealed.

  1. 1. Click the start game section.
  2. 2. After start game section has been clicked, the computer's board will be generated.
